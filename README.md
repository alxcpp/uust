# Каталог мероприятий УГНТУ

Веб-сайт для просмотра и фильтрации мероприятий Уфимского университета науки и технологий (УГНТУ).

## Возможности

- 📅 Фильтрация по дате
- 🎯 Фильтрация по тематике (наука, образование, культура, спорт, карьера)
- 💻 Фильтрация по формату (очный, онлайн, гибридный)
- 📱 Адаптивный дизайн для всех устройств
- ⚡ Быстрая работа без серверной части

## Запуск через Docker Compose

Установите Docker с поддержкой Compose, затем из каталога проекта выполните:

```bash
docker compose up --build -d
```

Сайт будет доступен по адресу http://localhost:8080. Чтобы остановить его:

```bash
docker compose down
```

Для быстрого просмотра без Docker можно открыть `index.html` в браузере.

## Технологии

- HTML5
- CSS3 (с CSS-переменными и Flexbox/Grid)
- Vanilla JavaScript (без зависимостей)

## Структура

- `index.html` - основной файл сайта, содержит всю разметку, стили и скрипты
- `Dockerfile` - образ Nginx для раздачи сайта
- `compose.yaml` - конфигурация Docker Compose

## Данные о мероприятиях

Информация о мероприятиях хранится в массиве `events` внутри `index.html`. Для обновления данных отредактируйте этот массив, добавив новые объекты мероприятий со следующими полями:

```javascript
{
    id: уникальный_номер,
    title: "Название мероприятия",
    date: "ГГГГ-ММ-ДД",
    description: "Описание мероприятия",
    topic: "наука|образование|культура|спорт|карьера",
    format: "очный|онлайн|гибрид",
    location: "Место проведения"
}
```
